一只手动球阀，外面能看到的是阀体、两端六角和一根长手柄。把外壳打开后，球芯、阀座、阀杆、填料和紧固件之间的关系，才是这次建模更值得梳理的部分。

这次我根据一张参考图，在 **SolidWorks Premium 2025 SP5.0** 中建立了一个 DN25 手动丝口不锈钢球阀。整个模型包含 **12 种零件、13 个组件**，两端采用实体内螺纹，原生文件保留草图、特征树、装配配合和爆炸视图。

建模通过 Python 调用 SolidWorks 原生 COM 接口完成。下面按结构理解和复现的顺序，记录尺寸怎么确定、零件怎么拆分，以及自动化过程中实际遇到的问题。

![DN25 手动球阀完整装配，包含两端六角、实体内螺纹和蓝色手柄护套](/images/dn25-ball-valve/09_assembly.png)

*图 1｜完整装配状态。本文配图均由实际 SolidWorks 视口导出。*

## 先确定尺寸和模型用途

参考图能够说明外形比例，却没有提供制造尺寸。因此，这次先定义一组用于结构展示和建模练习的尺寸，再围绕它们建立零件。

| 项目 | 本次模型取值 |
| --- | --- |
| 公称规格 | DN25 |
| 直通流道 | Φ25 mm |
| 阀体端到端长度 | 90 mm |
| 中部阀体外径 | Φ50 mm |
| 两端六角对边 | 46 mm |
| 球芯直径 | Φ39 mm |
| 钢手柄宽度 | 18 mm |
| 管道接口 | 两端 G1 平行内螺纹示意 |
| 金属件材料 | SolidWorks 材料库中的 AISI 304 |

这里需要分清公称规格、流道尺寸和螺纹尺寸。**DN25 不能直接当成 G1 螺纹的大径。** Swagelok 的螺纹识别表中，1 英寸 ISO 228/1 平行螺纹的外螺纹识别直径约为 33.25 mm，内螺纹识别直径约为 30.29 mm，均为每英寸 11 牙。识别表用于辨认接口，具体加工仍需依据标准和公差要求。[螺纹和端接识别指南](https://www.swagelok.com/downloads/webcatalogs/en/ms-13-77.pdf)

本模型据此取螺距 `25.4 / 11 ≈ 2.30909 mm`，使用 Φ30.292 mm 底孔和 55° 牙型。外形比例、阀座接触区和端盖连接结构采用教学简化；承压壁厚、密封压缩量与制造公差需要结合实际产品要求继续设计。

## 用统一坐标组织零件

在开始画草图之前，我先统一了两个方向：**管道轴沿全局 Z 轴，阀杆轴沿全局 Y 轴**。完整装配中，手柄沿管道方向延伸。

这样，阀体、端盖、球芯和阀座可以围绕同一个原点建立，各段的轴向位置直接写进草图和拉伸偏置。阀杆及其同轴附件在零件文件中沿 Z 轴建模，插入装配后再旋转到 Y 轴。

这套约定也用于 Python 脚本。尺寸记录统一使用毫米，传入 SolidWorks API 时再换算为米，避免在每个特征里混用单位。

| 结构分组 | 零件 | 装配数量 |
| --- | --- | --- |
| 外壳 | 阀体、右端盖 | 2 |
| 内部流道 | 球芯、左右阀座 | 3 |
| 阀杆与上部附件 | 阀杆、填料、压盖、限位板、垫圈、螺母 | 6 |
| 操作手柄 | 折弯钢手柄、蓝色护套 | 2 |

左右阀座复用同一个零件文件，因此零件种类是 12 种，装配中的组件数量是 13 个。

## 阀体与端盖先把内部空间留出来

阀体从同心圆环开始：外圆 Φ50 mm、内圆 Φ40.4 mm，沿 Z 轴拉伸出中部外壳。随后添加左端六角和阀座支承台阶，再从上方建立阀杆颈部。

颈部的孔分成三个层次处理：阀杆通孔、填料沉孔和轴肩沉孔。分别建立这些特征后，后续调整阀杆或填料尺寸时，就能找到对应的修改位置。

![阀体零件，展示左端六角、中部外壳和上方阀杆颈部](/images/dn25-ball-valve/01_body.png)

*图 2｜阀体承担外壳、阀座支承和阀杆安装三个部分的几何表达。*

右端盖单独建立，包含定位止口、圆形肩部和右端六角。止口外径取 Φ40.2 mm，与阀体内腔对应。把端盖拆成独立零件，也方便在爆炸视图中展示内部结构。

这里的止口主要表达定位关系，实际端盖连接和密封细节仍属于后续产品设计的内容。

## 两端内螺纹使用螺旋线和扫描切除

这次选择建立实体螺纹，让端口的牙形在普通视图和爆炸图中都能看清。两端都采用“基圆、螺旋线、闭合牙型、扫描切除”的顺序。

1. 在端口附近建立等距基准面，画出 Φ30.292 mm 基圆。
2. 用基圆生成高度 17.6 mm、螺距约 2.30909 mm 的螺旋线。
3. 在右视基准面绘制闭合牙型，使它与螺旋线起点对应。
4. 将牙型作为轮廓、螺旋线作为路径，执行扫描切除。
5. 为六角端口的外轮廓添加 1.2 mm、45° 倒角。

![右端盖及 G1 实体内螺纹，端口外缘带倒角](/images/dn25-ball-valve/02_endcap.png)

*图 3｜端盖保留螺旋线、牙型草图和扫描切除特征，便于继续编辑。*

牙型保留 55° 夹角，牙顶和牙底用截平方式简化。这个处理能表达螺纹的空间形状，但不能据此判断标准牙型公差或密封性能。

## 球芯与阀座围绕同一条流道建立

球芯的主体由 R19.5 mm 半圆旋转 360° 得到，再沿 Z 轴切出 Φ25 mm 流道。顶部切出 6.4 × 8.4 mm 的矩形驱动槽，与阀杆下端 6 × 8 mm 的扁榫对应。

![球芯零件，展示贯通流道和顶部矩形驱动槽](/images/dn25-ball-valve/03_ball.png)

*图 4｜球芯的流道与驱动槽分别对应流体通路和阀杆连接位置。*

两侧阀座使用同一个零件文件：外径 Φ39.4 mm、内径 Φ25 mm，球面接触区域采用台阶让位简化。装配时右阀座保持原方向，左阀座绕 Y 轴旋转 180°。

![阀座零件，展示环形流道和内侧让位台阶](/images/dn25-ball-valve/04_seat.png)

*图 5｜左右阀座复用同一零件，装配时调整方向。*

阀座与填料采用象牙白外观，表达 PTFE 密封件的设计意图。外观赋色只帮助识别零件，本次没有建立材料强度或密封仿真。

## 阀杆和上部附件逐层连接

阀杆包含轴身、轴肩、上下两个驱动扁榫，以及上端 Φ8 mm 的简化螺纹轴。下端与球芯驱动槽对应，上端与手柄安装孔对应。

![阀杆零件，包含轴肩、驱动扁榫和上端简化螺纹轴](/images/dn25-ball-valve/05_stem.png)

*图 6｜阀杆把球芯与手柄连接起来，上端紧固螺纹在本模型中简化为光轴。*

沿阀杆向上，依次安排填料、压盖、限位板、手柄、垫圈和锁紧螺母。压盖用肩环加六角建立，中心孔与阀杆保持对应；限位板则用环板和侧面的限位耳表达外形。

![压盖零件，展示肩环、六角外形和中心通孔](/images/dn25-ball-valve/06_gland.png)

*图 7｜压盖单独建模，肩环和六角特征可以分别调整。*

这一组零件也暴露了装配检查的价值：初始限位耳与压盖六角发生互穿，后来将限位耳内缘的 X 坐标从 −10 mm 调整为 −13 mm。阀杆轴肩沉孔、上端扁榫和手柄孔也经过尺寸修正。

## 折弯手柄与护套分别建模

钢手柄先在前视面画侧面折线，包含连接端、抬高的折弯段和长直段，再拉伸成 18 mm 宽的钢板。连接端切出扁孔，与阀杆上端扁榫对应。

![折弯钢手柄，展示连接端、折弯过渡和长直段](/images/dn25-ball-valve/07_handle.png)

*图 8｜从侧面轮廓建立手柄，折弯高度和长直段的位置都保留在草图中。*

蓝色护套作为独立零件建立，外轮廓由长条和半圆端头组成，内部切出插入槽，给钢手柄留出装配间隙。

![蓝色手柄护套，展示圆头外形和内部插入槽](/images/dn25-ball-valve/08_blue_grip.png)

*图 9｜独立护套可以在爆炸视图中移开，展示与钢手柄的关系。*

将护套与钢手柄分开保存后，颜色、可见性和爆炸位置都可以单独控制。

## 装配与爆炸视图使用明确的方向

装配时先固定阀体，再依次插入其余组件。各零件的位置已经通过草图坐标和偏置定义，装配阶段主要处理方向变换，并用 **12 个锁定配合**保存展示姿态。

当前装配用于结构展示，没有建立球芯与手柄的开关运动联动。如果要自由拖动某个组件，需要先抑制它对应的锁定配合；进一步做运动演示时，还需要重新组织运动约束。

爆炸视图沿两个方向展开：端盖、球芯和阀座沿管道轴分开；阀杆及上部附件沿竖直方向依次抬高。蓝色护套先随手柄上移，再单独横向移开。

![DN25 球阀爆炸视图，内部零件沿管道轴展开，上部附件沿阀杆轴展开](/images/dn25-ball-valve/10_exploded.png)

*图 10｜爆炸视图包含 12 个步骤，便于观察零件的装配层次。*

这里遇到的一个问题是，爆炸方向可能受到组件自身旋转的影响。最后删除了软件自动生成的默认爆炸链，通过标准基准面建立全局 X、Y、Z 参考轴，再为每一步显式指定方向。

在配置管理器中右键“爆炸视图1”，就可以切换爆炸与解除爆炸。爆炸步骤只改变展示位置，零件原始几何和装配配合保持原有定义。

临时隐藏阀体和端盖，还可以直接观察球芯、两侧阀座及阀杆的相对位置。导出图片后恢复外壳可见性，模型最终保存为完整装配状态。

![隐藏阀体和端盖后的内部结构，展示球芯、阀座与阀杆的位置关系](/images/dn25-ball-valve/11_internals.png)

*图 11｜内部视图把完整装配中被外壳遮挡的连接位置单独展示出来。*

## Python 自动化中需要处理的细节

脚本调用的是 SolidWorks 的原生草图、拉伸、旋转、螺旋线、扫描切除和装配接口，因此生成的文件保留了可编辑特征。自动化主要负责重复操作、尺寸输入、命名和记录，几何关系仍需要在建模前明确。

这次有几处问题值得留下来：

- **COM 类型信息。** 本机对象没有自动提供可靠的接口类型信息，最终读取已安装的 `sldworks.tlb`，并显式转换为 `ISldWorks`、`IModelDoc2` 等接口。生成的类型缓存留在项目目录中。
- **数组类型。** 普通 Python 元组传入外观属性时，出现颜色和透明度异常，改为 double 类型的 SAFEARRAY 后恢复。
- **基准面方向。** 本机上视基准面法向为 +Y，相关拉伸、切除和护套内腔需要使用一致的方向约定。
- **返回状态。** 本次配合调用与爆炸步骤使用了不同的成功返回码，脚本分别判断，不能统一假设某个整数就代表成功。
- **临时文件。** 批量检查时跳过 SolidWorks 生成的 `~$` 锁文件，避免把它们当成零件打开。

外观数组的关键写法如下，`doc` 为已取得的 SolidWorks 文档对象：

```python
import pythoncom
from win32com.client import VARIANT

# 显式传入 double SAFEARRAY，使 COM 按外观属性所需类型读取数组。
doc.MaterialPropertyValues = VARIANT(
    pythoncom.VT_ARRAY | pythoncom.VT_R8,
    (0.72, 0.75, 0.78, 0.3, 0.75, 0.45, 0.3, 0.0, 0.0),
)
```

脚本同时保留带时间、对象和参数的操作流水。记录中包含调整尺寸、修正方向和重建爆炸视图的过程，方便把最终模型与产生它的操作对应起来。

项目最终检查记录给出的结果如下。干涉检查不把单纯接触计为干涉。

| 原生零件文件 | 12 个 |
| 每个零件的实体数 | 均为 1 |
| 零件特征错误 | 0 项 |
| 装配组件 | 13 个 |
| 装配特征错误 | 0 项 |
| 装配重新打开错误 / 警告 | 0 / 0 |
| 实体干涉 | 0 项 |
| 爆炸视图步骤 | 12 步 |

这些检查确认了当前模型的几何和装配状态。密封、承压与运动性能需要通过各自的设计和验证流程判断。

保存结果包括原生 `SLDPRT`、`SLDASM` 和成功导出的 Parasolid `.x_t` 文件。原生装配体与 `parts` 目录需要保持相对位置，才能继续找到组件引用。STEP 导出在本机返回通用错误 1，未生成有效文件，因此这次通用格式以实际导出的 Parasolid 为准。

对我来说，这次建模最有价值的部分，是把参考图中的外形拆成有明确坐标、尺寸和装配关系的零件，再用爆炸视图检查这些关系是否表达清楚。下一步如果继续完善，会先处理端盖连接与阀座接触细节，再为手柄和球芯建立开关运动约束。
