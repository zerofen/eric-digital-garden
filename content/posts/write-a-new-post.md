这是一篇**使用指南示例**，用来展示博客的正文排版，也帮助你开始维护自己的文章。

## 从一个文件开始

在项目的 `content/posts/` 目录下新建一个 Markdown 文件，例如 `my-first-post.md`。文件名使用小写英文和短横线，它会成为文章地址的一部分。

也可以运行下面的命令自动生成草稿：

```bash
npm run new-post -- my-first-post "我的第一篇文章"
```

新文章默认是草稿。准备发布时，把顶部的 `draft: true` 改成 `draft: false`。

## 文章的开头

每篇文章开头都有一小段信息：

```yaml
---
title: '我的第一篇文章'
description: '用一两句话，告诉读者这篇文章写了什么。'
date: '2026-09-07'
tags: ['生活', '随笔']
draft: false
---
```

日期请保留引号。保存文件并重新构建后，首页、文章列表和订阅源都会自动更新。

## 让文字更好读

用二级标题整理文章，用 **加粗** 标出重点，用列表梳理步骤。长段落可以拆成几个短段落，给阅读留一点呼吸的空间。

| 写作元素 | Markdown 写法                |
| -------- | ---------------------------- |
| 二级标题 | `## 标题`                    |
| 加粗     | `**重点**`                   |
| 链接     | `[文字](网址)`               |
| 图片     | `![说明](/images/photo.jpg)` |

图片放在 `public/images/` 中。引用时不用写 `public`，只需从 `/images/` 开始。

## 写到哪里，算哪里

不必等所有事情都想明白再动笔。今天留下的问题，也许就是明天文章的起点。
